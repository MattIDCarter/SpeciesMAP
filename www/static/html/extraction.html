1. Define Area of Interest: either upload your polygon file (accepted file types shown below), draw it on the map, or input/paste coordinates. For draw and coordinate options, only one polygon can be used at a time.
  2. Select dataset: Species 1 or Species 2.
  3. Would you like to add a buffer around your area of interest?
  4. What size buffer would you like to add? (km) - only available if a buffer is selected.
  5. Press "Calculate". If you would like to calculate estimates for a new area, press "Reset" and return to Step 1.
